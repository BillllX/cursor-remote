Jiebo · 远端工作台 2026.09 · 草案
01 定位

它是什么

接驳是远端工作台。人在浏览器里交代，机器在工作区里改文件、跑命令。浏览器只是席位，不是 IDE。

沉稳

像车间的接驳台，不像硅谷聊天玩具。少装饰，不发光，不堆渐变。

好上手

中文先于英文。短句、口语、不把模型名当卖点。

可主张

图形、色、字、文案都能独立主张版权，不靠任何现成产品的外形来解释自己。

03 标志

榫卯接扣

两块错位的圆角板扣在一起，中间一枚销。意思是两边接上：浏览器这一头，工作区那一头。不是星星，不是光标，不是三角形。

从左到右：单色标、双色标、应用图标、反白标。

使用规则

  • 保护空间 = 标宽的 1/4，四周留白。
  • 最小尺寸：标 16px，应用图标 28px，横锁 120px。
  • 不要旋转、不要加描边、不要把两块板对齐成一个矩形。
  • 不要改成四角星、火花、鼠标箭头。
04 色彩

暖纸与松绿

默认浅色。Cursor 是冷黑加冰蓝；接驳是牙白纸、松烟绿、赭金。强调色走绿，不走蓝。

08 规避

咨询材料里不要出现

图形

四角星 / 火花、旋转菱形、鼠标箭头、VS Code 四格、ChatGPT 绿点、Claude 星芒。

界面

近黑侧栏 + 冰蓝链接、Composer 黑洞、Agent 小字、Cursor 式空状态三星标。

文案

产品名、仓库名、窗口标题、路径 /cursor-remote、环境变量展示里带 Cursor。

邻近品牌

也不要看起来像飞书、微信、腾讯会议或元宝。主色不用腾讯蓝、微信绿。

09 组件库

借用行为，不借用皮

网上现成的库分三层：无样式行为、中文组件清单、气质参考。接驳自己出皮。装谁的默认主题，咨询材料就会长成谁家的产品。

层选用做法
采用行为 Base UI · @base-ui/react · MIT Radix 原班人马的后继，无样式、可访问。Dialog / Menu / Popover / Tabs / Switch / Tooltip / Combobox / Accordion / Toast。直接用它，不要再套 shadcn 默认皮。
采用图标 Phosphor Icons · MIT Regular 字重，线宽当 token。Lucide 是 shadcn / 多数 AI 编程产品的默认图标，避开。品牌关键符号（接扣、发送）仍用自制 SVG。
对照清单 Ant Design 6 中文最全的企业组件地图：Mentions、Upload、Tree、Empty、Message、Form。只对照覆盖面和中文命名，不启用默认蓝 #1677FF。
对照咨询 TDesign React 腾讯开源企业库，组件分类和 API 习惯可对照。默认皮肤一眼就是腾讯内部产品，咨询材料里不要装、不要截图默认主题。
参考API Park UI · Ark + Panda · MIT 变体模型可抄：solid / subtle / surface / outline / plain。色板用的是 Radix Colors，视觉不要跟。
参考气质 bpdm/ui 的 paper / mist 暖纸浅色、CSS 变量换肤，和接驳最近。尚在 0.1，周下载百余，且默认 Lucide，只看不装。
不用皮肤 shadcn/ui、Arco、Semi、Ant 默认主题、TDesign 默认主题、assistant-ui 不是不能用它们的代码思路，是不能带着它们的默认长相进咨询材料。

base-ui.com phosphoricons.com Ant 组件总览 TDesign 概览 Park 主题 bpdm paper
