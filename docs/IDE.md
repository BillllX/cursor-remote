# 接驳 IDE 规格（网页 + iPad）

把「接驳」从远程聊天窗做成可以整天拿来写代码的 IDE。Agent 仍跑在网关所在机器的工作区里（Cursor SDK 或第三方纯问答），两端看到同一套会话、文件和 Loop。网页偏桌面，三区同时摆开。iPad 屏幕留给对话；文件、搜索、Git、终端、编辑和 Loop 都从侧栏进，用浮层叠上，关掉就回到对话。

本文是开发循环的合同：每一拍只做下面清单里的一刀，做完勾选，再等下一拍。

## 1. 现在已经有的

两端共用 WebSocket 协议（`shared/protocol.ts`）。

- 对话：Agent / Plan / Ask，模型选择，排队与取消，确认写入，检查点，Crew（摸仓库 / 改代码 / 交叉审）
- 文件：工作区树、Git 状态徽章、预览（文本 / 图片 / HTML / Canvas）、分享与存相册（iPad）
- 会话：多会话、工作区分组、草稿、分段加载、改名
- 账号：多租户、管理员用量
- 第三方模型：`providers.json`，MiniMax M3 / M2 纯问答（无工具）

网页已经比聊天窗多一截：文件与搜索是浮层（`⌘K` / `⌘⇧F`），预览标签能改文本并 `write_file` 保存，Git 改动能保留或还原。这些能力叠在对话上面，收起预览就回到聊天布局，没有常驻三区，也没有终端底栏。

iPad 的主区是对话。文件浏览是全屏盖层，预览从右侧滑出，Loop 已经是侧栏里的表单。文本还不能改完保存，也没有搜索和终端。接下来这些非对话界面都收到侧栏，用同一套浮层叠上去，主区不再分出编辑器或底栏。

Loop 两端都已经能开：网页在侧栏，iPad 在侧栏表单里。README 里「不复刻完整 IDE」在 R1 勾选后改掉。

## 2. 目标形态

用户不离开接驳就能：打开文件、改完保存、搜索、看 Git 改动、看终端输出、让 Agent 改代码，并且能挂一个 Loop 让 Agent 按间隔自己继续干，直到停条件满足或用户停下。

### 网页

三区，可拖拽宽度：

1. 左：活动栏（对话、文件、搜索、Git、终端、Loop、助理）+ 对应侧栏
2. 中：编辑器标签（文本可编辑保存；图片 / HTML / Canvas 仍走现有预览）
3. 右：当前会话的 Agent 线程与输入框

底栏可收起：终端、问题（先做终端输出流，问题列表后补）。

窄屏（< 960px）退成「侧栏抽屉 + 主区」，和现在的 sheet 手势同一套。

### iPad

主区只有当前对话。非对话功能走同一套浮层，不再同时用 sheet、全屏盖层和右侧预览三套壳。

侧栏底部和收起后的图标栏是同一组入口，顺序固定：文件、搜索、Git、终端、Loop、助理。图标栏最上是展开侧栏。管理员统计留在图标栏底部，和这六个功能隔开。当前打开的入口要高亮；再点一次高亮图标，关掉这一层。Loop 在跑时、助理有未读或待批时，图标上保留同一个小点。

浮层最多两层：

1. 工具层：文件、搜索、Git、终端、Loop、助理。同一时间只开一个，切换是替换，不叠多个工具。
2. 内容层：编辑、只读预览、diff。叠在工具层上面。换一个文件是换掉这一层，不叠第三张。系统分享和 Quick Look 不算层。

从对话里点文件引用，可以直接开内容层，关掉就回到对话。

关掉最上面一层回到下面那层。点遮罩只关最上层。全部关掉后，主区仍是整宽对话，预览不留在右侧。

浮层里的事：

- 文件：单栏文件树。点文本开编辑，点图片、HTML、Canvas 开只读预览
- 编辑：可保存，有脏标记。关闭回到文件树
- 搜索：未输入时提示「搜文件名或内容」；没有命中时说明搜的是什么。结果打开编辑或预览
- Git：没有改动时写「工作区干净」。点开 diff，保留和还原仍可用
- 终端：没有输出时写「这个会话还没有 shell 输出」
- Loop：表单不变，只是放进同一套浮层

窗口窄于 600pt 时，浮层改成全宽单列，层与层前后切换。再窄也不改成左右分栏。宽一点时，工具层旁边仍能看见一条对话。

输入框里用来 @ 引用文件的选择器保持独立，不并进这套浏览浮层。

### 两端共同规则

- 同一 `chatId`、同一工作区路径，网页改完 iPad 重开文件能看到
- 保存走网关写盘，不把文件正文塞进对话
- Agent 正在改的文件：编辑器标脏；用户未保存的缓冲不被 Agent 静默覆盖，冲突时提示
- 第三方纯问答模型没有工具，编辑器保存不依赖它

## 3. Loop（产品能力）

Loop 是挂在某个会话上的重复任务，不是开发循环本身。

用户给出：

- 目标（一段 prompt，每拍原样发给该会话的 Agent）
- 间隔（30 秒到 24 小时；默认 15 分钟）
- 停条件（可选一句，例如「测试通过」或「最多 8 拍」）
- 模型与模式（默认沿用该会话当前选择；Ask 纯问答也可以 Loop）

运行时：

1. 用户点「开始 Loop」。网关记下 `loop` 状态（内存 + `stateDir/loops.json`，重启可恢复未完成的 Loop）。
2. 到点后，若该会话没有在跑的 run，网关用 Loop 目标发一轮 prompt（带上一拍摘要，避免失忆）。若正在跑，本拍顺延，不并行第二轮。
3. 每拍结束写一条 `loop_tick`：序号、状态（ran / skipped / stopped / error）、一句话摘要。
4. 停：用户点停止、达到最大拍数、或 Agent 在回复末行输出约定标记 `LOOP_DONE`。
5. 断线：Loop 继续在网关跑；重连后 `ready` 带上该租户的 loop 列表，两端补画。

不做的：不在客户端用 `setInterval` 当唯一调度（关网页 Loop 不能停）；不让 Loop 跨租户；不让 Loop 改间隔短于 30 秒。

### 协议（L1 实现时加进 `shared/protocol.ts` 与 iOS `Protocol.swift`）

客户端 → 网关：

- `loop_start`：`chatId`，`goal`，`intervalSec`，`maxTicks?`，`model?`，`mode?`
- `loop_stop`：`chatId`

网关 → 客户端：

- `loop_state`：`chatId`，`status`（idle / armed / running / stopped），`goal`，`intervalSec`，`tick`，`maxTicks?`，`lastSummary?`，`nextAt?`
- `ready.loops`：当前租户未停止的 loop 列表（形状同 `loop_state`）

## 4. 开发循环（怎么一刀一刀做）

这是给本会话里的 Agent 用的，和产品 Loop 不是一回事。

- 状态文件：`docs/ide-loop-state.json`
- 哨兵：`AGENT_LOOP_WAKE_IDE`
- 节奏：上一拍结束后 3 分钟再做下一刀。若本拍发现 `inProgress` 且 `startedAt` 在 90 分钟内，跳过并重新等 3 分钟，避免两拍叠在一起
- 模型轮换：`kimi-k3-max` → `glm-5.2-high` → `grok-4.7-xhigh-fast`，实现用当前下标的模型。只用这份名单里的 slug
- 一拍只做清单里**第一个未勾选**的切片。做不完就在状态里写 `note`，不要顺手下一个
- 网页改动用浏览器走通主路径；iPad 改动至少 `xcodebuild` 通过。验证失败先修再勾选
- 做完必须同时请这三个模型评审。三个都给出 PASS 或 PASS_WITH_MINOR 才能勾选并进入下一刀。任一 FAIL，或还有 CRITICAL / MAJOR，当拍修完后只请没通过的模型复审。MINOR 记进备注，不挡通过。评审没齐之前不武装下一拍，也不做下一刀
- 不改无关文件。不提交 git，除非用户当次明确说提交
- 用户说停循环：杀掉心跳进程，把 `docs/ide-loop-state.json` 的 `running` 设为 false

每拍步骤：

1. 读本文勾选区和状态文件
2. 把状态设为 `inProgress: true` 并写下 `startedAt`
3. 用轮换模型实现该切片（网页或 iPad 以切片标题为准）
4. 验证
5. 同时请 Kimi、GLM、Grok 评审。没全部通过就修，再复审
6. 三个都通过之后才勾选，把 `rotationIndex` 加 1、`inProgress: false`、写 `lastSlice`
7. 然后才武装下一拍心跳（上一拍结束后 3 分钟，见状态文件里的 `wake`）

### Loop

- [x] **L1 协议** — `shared/protocol.ts`、网页协议副本、iOS 编解码、网关解析 `loop_start` / `loop_stop` 并回 `loop_state`（只登记，到点执行在 L2）。间隔、字数、拍数校验有单测

## 6. 验收（R1 才算整份规格做完）

在生产或本地网关（同一租户）上：

1. 网页把某个文本文件改一个词并保存，iPad 打开同一路径看到新词
2. 搜索能命中这个词
3. 让 Agent 跑一条会出 shell 输出的指令。网页在底栏看到，iPad 在侧栏「终端」浮层里看到
4. 对一个会话开始 Loop（间隔 30 秒，最多 2 拍），两拍都出现在线程里，然后状态变为 stopped
5. 关掉网页再打开，编辑器里没有丢失已保存内容；未保存的脏缓冲允许丢，但要有过提示

## 7. 明确不做（除非以后单开规格）

- 不把 Monaco 全套语言服务搬上 iPad
- 不做调试器、不做多光标、不做插件市场
- 不给第三方纯问答模型加工具
- 不把 Loop 间隔做到 30 秒以下
- 不在本规格里改多租户隔离模型
